## 1. Что это

**iSearch** — локальный/демо-сервис поиска редкой и винтажной одежды.

1. Пользователь пишет запрос текстом и/или прикладывает фото.  
2. Сервер разбирает критерии (категория, цвет, размер, бюджет, бренд и др.).  
3. Открываются ссылки на поиск площадок (Ozon, Wildberries, Авито и т.д.).  
4. **Цены и наличие не проверяются и не выдумываются** — только на площадке.

Стек: **Node.js ≥ 18**, один `server.js`, **без npm-зависимостей** (`npm start` = `node server.js`).

## 2. Как запустить локально

```powershell
cd C:\AI\ai-demo
copy .env.example .env
# при необходимости отредактируйте .env
npm start
```

Открыть: http://localhost:3000  

Если порт 3000 занят:

```powershell
$env:PORT='3001'; $env:HOST='0.0.0.0'; node server.js
```

### Фото (Ollama)

1. Установить [Ollama](https://ollama.com).  
2. Скачать модель (выбрана под RTX 4060 Ti):

```powershell
ollama pull qwen3-vl:4b-instruct
```

3. В `.env`: `AI_ENABLED=true`, `OLLAMA_MODEL=qwen3-vl:4b-instruct`.  
4. Перезапустить сервер — появится кнопка «Фото».

На хостинге **без** Ollama: `AI_ENABLED=false` — текст работает, кнопка «Фото» скрыта.

## 3. Переменные окружения (`.env.example`)

| Переменная | Смысл |
|------------|--------|
| `AI_ENABLED` | `true` — фото через Ollama; `false` — только текст |
| `PORT` / `HOST` | порт и bind (`0.0.0.0` для хостинга) |
| `WEB_SEARCH_ENABLED` | веб-поиск (по умолчанию выкл., без платных ключей) |
| `OLLAMA_URL` | обычно `http://127.0.0.1:11434` |
| `OLLAMA_MODEL` | `qwen3-vl:4b-instruct` |
| `PHOTO_TIMEOUT_SEC` | таймаут разбора фото (90 с) |
| `PHOTO_PIPELINE` | `schema` (рекомендуется) / `twopass` / `auto` |

Ключи API — только в `.env`, не во frontend и не в чат.

## 5. API

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/health` | статус; при `AI_ENABLED=false` Ollama **не** дергается |
| `POST` | `/api/search` | `{ query, image?, attributes? }` → `parsed`, `photo`, `sources` |

Лимиты: ~20 запросов/мин с IP; тело без AI до 64 КБ, с AI до ~9 МБ.  
Заголовки: `X-Content-Type-Options`, `X-Frame-Options`, CSP и др.  
Приватные пути (`/server.js`, `/data/…`, `/.env`, `/scripts/…`) → 403.

## 6. Что сделано по этапам (прогресс)

### Поиск и честность
- Текстовый разбор правилами (`lib/parse-query.js`).
- Ссылки на площадки без парсинга цен.
- Честные ошибки (фото не подменяется «успехом»).

### UI
- Светлая / тёмная тема (`js/theme.js`).
- Официальный тон: «Поиск редкой и винтажной одежды» (без TikTok-подачи).
- Блок **«Критерии запроса»** сразу в выдаче: категория, цвет, размер, бюджет, бренд…
- Правка полей + **«Искать снова»**.
- Разбор фото в результатах (если был).
- Копирование поисковой фразы.
- Параметр URL `?q=…`.
- Секция «Как устроен поиск», расширенная страница «О проекте».

### Фото / AI
- Structured JSON Schema + `temperature: 0`, `think: false`.
- Расширенные поля: тип, подтип, цвета, материал, фурнитура, `visible_text`, brand/model **только если видны**.
- Сравнение **schema vs twopass** → выбран **schema** (`PHOTO_PIPELINE=schema`).
- Железо пользователя: Ryzen 5 7500F, RTX 4060 Ti → модель **`qwen3-vl:4b-instruct`** (3.3 GB).
- Старая `qwen3-vl:2b` без `-instruct` часто отдавала пустой `content` (ответ в thinking) — не использовать.

### Подготовка к публикации (ШАГ 1)
- Bind `0.0.0.0`, `engines`, security headers, `.gitignore`, README.
- Публичный режим без Ollama проверен (`AI_ENABLED=false`).

### Выкладка (не завершена)
- **ШАГ 2 GitHub** — инструкции даны, push ждёт вашего аккаунта.
- **ШАГ 3 хостинг** — рекомендован **Render** (бесплатно, без карты; засыпает ~15 мин; возможны сбои из РФ). Альтернативы: Railway, Amvera (платно от ~170 ₽, удобнее для РФ).
- **ШАГ 4–6** (деплой, домен, финальный чек) — ещё не делались.
