## 3. Admitad (приоритет №1)

**Сайт:** https://www.admitad.com / https://www.admitad.ru  
**Цена для вебмастера:** регистрация и работа **бесплатно** (сеть зарабатывает на рекламодателях).  
**Что даёт:** товарные фиды XML / CSV / Google Merchant у программ, где включён инструмент «Товары».  
**Справка по экспорту:** https://support.admitad.ru/article/ru/86.html  
**Каталог одежды:** https://www.admitad.ru/store/internet-magaziny/odezhda-obuv-aksessuary/

### 3.1. Что сделать на сайте

1. Войти в кабинет вебмастера (у вас уже есть контакт с Admitad — используйте существующий аккаунт).
2. Убедиться, что площадка **VishFind** добавлена и по возможности **одобрена**.
3. Открыть **Admitad Store**.
4. Фильтры:
   - категория: **Интернет-магазины → Одежда, обувь, аксессуары** (и рядом «универмаги», если нужно шире);
   - инструмент: **Товары (Товарный фид)**;
   - регион: **Россия** / локальные, если есть;
   - по возможности вид трафика, который у вас разрешён (сайт / контент).
5. Открыть карточку программы. Проверить:
   - есть ли блок **Товары / фид**;
   - разрешён ли ваш тип трафика;
   - нужна ли модерация подключения;
   - GEO и запреты (часто режут бренд-контекст, кэшбэк и т.д.).
6. Нажать **Подключить** / отправить заявку на площадку VishFind.
7. После статуса «подключено» / «активно»:
   - путь A: программа → меню **Товары** → выбрать площадку и фид → скопировать XML/CSV;
   - путь B: кабинет → **Товары → Оригинальные** → площадка + рекламодатель + фид → **Сгенерировать** → скачать по ссылке.
8. Сохранить в таблицу: программа | статус | ссылка на фид | дата | валюта RUB.

**Обязательные поля в фиде (по справке Admitad):**  
`name`, `price`, `url`, `picture`, `categoryId`, `currencyID`.

### 3.2. Какие программы подходят нам

Подходят не «все», а те, где одновременно:

- ниша **одежда / обувь / аксессуары / спорт / универмаг с fashion**;
- есть **товарный фид**;
- площадка **может подключиться** (не вечный reject);
- ссылки в фиде — **партнёрские** (или сеть сама добавляет метки).

Искать в каталоге, а не по памяти. Ориентиры категорий:

- https://www.admitad.ru/store/internet-magaziny/odezhda-obuv-aksessuary/
- + фильтр «Товары».

Примеры типов (названия в Store меняются — сверяй карточку):

- крупные fashion / спорт / обувь с фидом;
- мультибрендовые магазины одежды с фидом (в Store встречаются программы вроде GroupPrice и аналоги — бери только если есть фид и одобрение).

**Не цель на месяц:** AliExpress «весь мир», финансы, ставки, adult, travel.
