# Сводка по данным VishFind (факт, не юр. вывод)

Кратко по текущей реализации. Без реквизитов владельца и без шаблона политики конфиденциальности.

## 1. Что принимает сервер (`POST /api/search`)

| Поле | Назначение |
|------|------------|
| `query` | Текст запроса (до 300 символов) |
| `attributes` / `attributes_priority` / `clear_attributes` | Правки критериев с UI |
| `image` | Base64 фото — только если `AI_ENABLED` и пользователь приложил снимок |
| `web_search: true` | Явный opt-in на внешний поиск ссылок; без флага веб-поиск не вызывается |

Иное (история, избранное, тема) на этот endpoint не отправляется.

## 2. Что передаётся Ollama Web Search

Только при **трёх** условиях сразу: `WEB_SEARCH_ENABLED=true` + ключ, пользовательский `web_search: true`, и политика источников допускает домены.

В `https://ollama.com/api/web_search` уходит JSON вида `{ query, max_results }`, где `query` — собранная строка (бренд / search_phrase / `site:…`), без фото, истории, избранного и технических полей UI.

`web_fetch` / HTML-сбор из этого шага **не** включаются пользовательским переключателем; fetch только при отдельном `OLLAMA_WEB_FETCH=true` и политике.

Автоматическое удаление всех возможных персональных данных из текста **не** обещается: делается усечение/санитизация строки запроса, не «анонимайзер».

## 3. Что хранится в браузере

- Тема (`vishfind-theme`)
- История поиска и избранное (`localStorage`)
- Опционально флаг тех. отладки
- Состояние переключателя веб-поиска **не** сохраняется: по умолчанию выключен при каждой загрузке страницы

## 4. Что хранится на сервере

- В памяти процесса: кэш результатов web_search (TTL), rate-limit счётчики, конфиг из env
- Постоянного пользовательского профиля / истории запросов на сервере в этой реализации **нет** (по коду `/api/search`)
- Реестры брендов/магазинов — файлы проекта, не персональные данные пользователя

## 5. Что пишется в логи

- Структурированные события (старт, warn/error): ошибки провайдеров, rate limit, сбои фото/веба
- Секреты и base64-фото маскируются логгером
- Полные тела запросов и сырые фото в лог **не** пишутся штатно
- Точный состав debug-метаданных зависит от `LOG_LEVEL` — см. `lib/logger.js`

## 6. Пока не установлено / вне среза кода

- Публичный контактный email / реквизиты оператора
- Юридическая квалификация обработки и сроки хранения у хостинга (Amvera и т.п.)
- Условия Ollama Cloud для web_search со стороны провайдера
- Полный перечень cookie/заголовков на стороне CDN или платформы деплоя
- Поведение сторонних сайтов после перехода пользователя по ссылке
