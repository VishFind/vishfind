# Локальная проверка анализа фото

**Дата:** 2026-10-28  
**Статус:** успешно (ручная/агентная проверка цепочки)

## Условия

- Сервер: `http://127.0.0.1:3103/` (оставлен работающим для ручной проверки)
- `AI_ENABLED=true`
- `OLLAMA_URL=http://127.0.0.1:11434`
- модель: `qwen3-vl:4b-instruct`
- `WEB_SEARCH_ENABLED=false`, `OLLAMA_WEB_FETCH=false` (не включались)

## Результат

| Поле | Значение |
|------|----------|
| Запрос | `POST /api/search` с `img/test-jacket.jpg` |
| HTTP | **200** |
| `photo_used` | **true** |
| Длительность | **~9 с** |
| Распознавание (кратко) | категория «куртка», цвет «красный» |

Локальная цепочка **браузер/API → свой сервер → локальная Ollama → ответ** подтверждена.  
Успех относится к **анализу фото**, не к текстовому fallback.

Облачный web_search / web_fetch и платные API в этой проверке не использовались.
